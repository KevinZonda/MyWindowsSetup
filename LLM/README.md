## Kimi Code Use API

After install kimi code, run `kimi` then modify `~/.kimi-code/config.toml`

```toml
[providers.kimi-for-coding]
type = "kimi"
api_key = "YOUR API KEY"
base_url = "https://api.kimi.com/coding/v1"
```
