# PCDN 自查

## 江苏/上海电信

电信 PCDN 特点是限制 MTU 1442。

$$
实际MTU = 发送ICMP包 + 28
$$

```sh
ping -s 1472 -M do 223.5.5.5 # Linux, MTU=1500
ping -l 1472 -f 223.5.5.5 # Windows, MTU=1500
```

黑屋 IP 段：
- ipv4: `116.226.x`, `101.80.x`, `61.173.x`, `218.78.x`

正常段：
- ipv4：`180.171.x`, `100.84.x`, `58.37.x`, `218.78.x`, `114.216.x`
